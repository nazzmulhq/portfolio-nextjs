## 🚀 Why QuickDB?

QuickDB turns your editor — or a dedicated desktop window — into a powerhouse database tool. Whether you're inspecting data, visualizing relationships, or letting AI write your queries, QuickDB gives you a seamless, context-rich experience.

- **Universal database support** — one interface for **85 engines** (PostgreSQL, MySQL, SQLite, MongoDB, Redis, ClickHouse, Snowflake, and 78 more) across **59 driver families**.
- **AI-ready MCP server** — expose your schema and data to AI agents (Cursor, Claude Desktop, Claude Code, Antigravity, VS Code, Windsurf, Continue, Cline, Roo Code, Kiro — **10 clients**) as **32 tools**.
- **IDE-grade Query Console** — autocomplete, live linting, go-to-definition, cancel, transactions, multi-tab, history and saved queries.
- **Visual Query Builder** — construct joins and aggregations without SQL.
- **Table Manager & data grid** — create/modify schema and edit rows inline.
- **Data visualization** — 255 chart styles from any query result.
- **Dashboards** — compose live chart / table / KPI-card widgets on a grid.
- **AI assistants** — NL→SQL, explain, optimize, fix, advisor, data quality.
- **Two products, one codebase** — the same features in the VS Code extension and the standalone desktop app.

## 📦 Install

**VS Code extension**

1. Open the **Extensions** view (`Ctrl/Cmd+Shift+X`).
2. Search for **QuickDB** → **Install**.
3. Click the **QuickDB icon** in the Activity Bar.

**Desktop app** (Windows / macOS / Linux) — download the installer for your OS: `.exe` (Windows), `.dmg` (macOS), `.AppImage` / `.deb` (Linux).

## 🏁 Quick Start

1. **Open QuickDB** — click the icon in the Activity Bar (extension) or launch the app (desktop).
2. **Add a connection** — click **`+`** (or run `QuickDB: Add Connection`). Pick your engine from the 85-engine grid, fill in the fields it shows (or paste a `postgres://` / `mysql://` URL), click **Test connection**, then **Create**.
3. **Browse** — expand the connection in the sidebar to see databases and tables; click a table to open the data grid.
4. **Query** — hover a connection and click **New Query** (or right-click → *New SQL Query*). Write SQL with autocomplete, press **Ctrl/Cmd+Enter** to run.
5. **Go further** — visualize a result, build a dashboard, or connect an AI agent via **Setup MCP for AI Clients**.
